## 典型代码 / 实验
聊天记录中的编译用例：
```bash
g++ hello.cpp -o hello
./hello
```
`-o hello` 指定输出可执行文件名。Git 流程是修改文件 → git add 暂存 → git commit 本地提交 → git push 上传远端。本次日志整理不执行提交或推送。

## 用户提出过的关键问题
- g++ 的 -o 是什么？答：指定输出文件名。
- git add 和 git commit 分别做什么？答：前者准备暂存内容，后者建立本地提交。
- git log --oneline 在哪里执行？答：仓库内；可先进入仓库根目录。
- 后续项目是否继续放在 ai-infra-learning 下？答：按该学习仓库组织练习目录。
