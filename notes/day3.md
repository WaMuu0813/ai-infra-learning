# Day3 — 生命周期、RAII、Copy / Move
日期：2026-09-09

## 当天学习内容
stack / heap、构造与析构、new / delete、对象生命周期、RAII；浅拷贝与深拷贝；右值引用、移动构造、std::move；unique_ptr 的独占所有权。

## 典型代码 / 实验
课堂浅拷贝反例（危险示例，不运行）：
```cpp
class Tensor {
    float* data = new float[100];
public:
    ~Tensor() { delete[] data; }
};
Tensor a;
Tensor b = a;  // 两个指针成员指向同一资源，两个对象都会尝试释放
```
深拷贝思路：为新对象分配独立存储，再复制元素。仅补拷贝构造并不自动解决拷贝赋值；完整资源管理还需考虑赋值等操作。

独占所有权转移的复习示例：
```cpp
auto p = std::make_unique<int>(42);
auto q = std::move(p); // q 接管资源，unique_ptr p 变为空
```

## 用户提出过的关键问题
- 析构函数何时调用？自动对象通常在离开作用域时析构；动态对象需由所有者负责释放。
- 拷贝构造与拷贝赋值有何区别？前者初始化新对象，后者更新已存在对象。
- Tensor&& 是什么？此处为右值引用参数。
- std::move 做了什么？进行值类别转换，为移动操作提供机会，本身不搬运资源。
- 为什么 move 常写 noexcept，vector 扩容为何可能 copy？这是与后续容器内容关联的复习问题，需结合异常保证分析。

## 犯过的错误及纠正
聊天回顾指出：问题不只是指针相同，而是多个对象都负责释放同一资源。移动后的对象也不能一概描述为 nullptr；unique_ptr 移动后为空是其特定保证，标准库许多其他类型是有效但状态未指定。
